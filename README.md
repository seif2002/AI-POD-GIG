# AI POD — Internal Policy Assistant

> **GIG Egypt Life Takaful** — AI-powered Q&A bot for HR & IT company policies.  
> Answers employee questions in **Arabic and English** using only internal documents — no hallucination.

---

## What It Does

AI POD is a **Retrieval-Augmented Generation (RAG)** system. You feed it your policy documents once; employees then ask questions in natural language and get grounded, cited answers. It refuses to answer when no relevant document exists.

Key properties:
- **Bilingual** — Arabic (RTL) and English, auto-detected per question
- **No hallucination** — answers sourced exclusively from your documents; explicitly says "not found" when below confidence threshold
- **Conversation memory** — follow-up questions like "how do I apply for it?" are understood from prior turns
- **Self-calibrating** — semantic similarity thresholds are tuned automatically to your specific document set
- **Fast** — Groq-hosted Llama models provide sub-second responses

## Quick Start

### 1. Clone & create environment

```bash
git clone https://github.com/omaralaa23/AIpod.git
cd AIpod
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

> **Note on pymupdf:** This project uses `pymupdf` (imported as `fitz`) instead of PyPDF2. pymupdf correctly handles Arabic/RTL text, complex fonts, and multi-column layouts.

### 3. Configure environment

Create a `.env` file in the project root:

```env
GROQ_API_KEY=gsk_your_key_here

# Optional conversation tuning
AI_POD_CONVERSATION_MAX_TURNS=10
AI_POD_GENERAL_CHAT_TEMPERATURE=0.75
AI_POD_CHAT_TITLE_MAX_CHARS=56
AI_POD_CHAT_PERSONA_EN=You speak like a warm, capable colleague: natural, concise, and present.
AI_POD_CHAT_STYLE_RULES_EN=For casual conversation, acknowledge the user's tone before answering. Ask one short follow-up question when the message is vague or emotional.
```

Get a free Groq API key at [console.groq.com](https://console.groq.com).  
Without the key the system falls back to returning raw document excerpts — no LLM synthesis.

### 4. Add your documents

Place `.pdf` or `.txt` files into the `HRandIT_documents/` folder.

**Language detection** (in order of priority):
1. Filename contains `english` / `arabic` → used as-is
2. File contains `=== LANGUAGE: EN ===` or `=== LANGUAGE: AR ===` markers
3. Character-set majority vote (auto-detect)

### 5. Ingest documents

```bash
python ingest_documents.py
```

This reads all documents, creates semantic chunks (with overlap), generates embeddings, builds the FAISS index, and auto-calibrates similarity thresholds. Run this again whenever documents are updated.

### 6. Run

**Web UI (recommended):**

```bash
python -m streamlit run web_interface.py
```

**CLI (for testing):**

```bash
python query_system.py
```

## Configuration (`config.py`)

| Setting | Default | Description |
|---|---|---|
| `EMBEDDING_MODEL` | `all-MiniLM-L6-v2` | Sentence transformer for embeddings |
| `LLM_MODEL_FAST` | `llama-3.1-8b-instant` | Default Groq model |
| `LLM_MODEL_ADVANCED` | `llama-3.3-70b-versatile` | For complex queries (wire in as needed) |
| `CHUNK_SIZE` | `1000` | Characters per chunk |
| `CHUNK_OVERLAP` | `200` | Overlap between chunks to preserve context at boundaries |
| `DEFAULT_SEARCH_K` | `15` | FAISS candidates retrieved per query |
| `TOP_K_RESULTS` | `3` | Chunks sent to the LLM |
| `MAX_FILE_SIZE` | `10 MB` | Per-file ingestion limit |
| `AI_POD_CONVERSATION_MAX_TURNS` | `10` | Number of prior conversation turns used for context |
| `AI_POD_GENERAL_CHAT_TEMPERATURE` | `0.75` | Creativity/warmth level for regular conversation |
| `AI_POD_GENERAL_CHAT_MAX_TOKENS` | `650` | Maximum response length for regular conversation |
| `AI_POD_CHAT_TITLE_MAX_CHARS` | `56` | Maximum length for summarized recent-chat titles |
| `AI_POD_CHAT_PERSONA_EN` / `AI_POD_CHAT_PERSONA_AR` | Warm colleague style | Configurable assistant persona |
| `AI_POD_CHAT_STYLE_RULES_EN` / `AI_POD_CHAT_STYLE_RULES_AR` | Friendly, concise style | Configurable conversation behavior rules |

## Conversation Memory

`query_system.py` maintains a rolling window of recent turns using `AI_POD_CONVERSATION_MAX_TURNS` from `.env` / `config.py`. The history is injected into every Groq API call so the model understands follow-up questions:

```
Employee: What is the annual leave policy?
AI POD:   Employees are entitled to 21 days per year...

Employee: How do I apply for it?          ← follow-up understood!
AI POD:   You submit a leave request via the HR portal...
```

In the CLI, type `clear` to reset memory. In the web UI, clearing chat history also resets memory.

## PDF Backend — pymupdf vs PyPDF2

| Feature | PyPDF2 (old) | pymupdf (current) |
|---|---|---|
| Arabic / RTL text order | Often scrambled | Correct |
| Complex fonts | Silent data loss | Handled |
| Multi-column layout | Merges columns | Preserved |
| Maintenance status | Largely abandoned | Actively maintained |
| Speed | Moderate | Faster |

## Troubleshooting

**"FAISS index not found"**  
→ Run `python ingest_documents.py` first.

**"No files found in documents directory"**  
→ Ensure `.pdf` or `.txt` files exist in `HRandIT_documents/`.

**Arabic text looks garbled in extracted chunks**  
→ Confirm `pymupdf` is installed (`pip install pymupdf`). Do not use PyPDF2.

**Groq API errors**  
→ Check your `.env` has a valid `GROQ_API_KEY`. The system works without it (basic mode) but won't synthesise answers.

**Low confidence on all questions**  
→ Re-run ingestion after adding more documents. Thresholds are recalibrated automatically.
